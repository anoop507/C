This program is designed to help you calculate and track your CGPA (Cumulative Grade Point Average) and SGPA (Semester Grade Point Average) based on the course data stored in a file named "courses.txt". The program provides an interactive menu to help you easily calculate and manage your grades. It supports the following key features:

Main Features:

CGPA Calculation:
The CGPA is calculated by summing the grade points of all the courses you have taken and dividing that total by the number of courses in the "courses". This gives you an overall average that reflects your cumulative performance across all semesters.

SGPA Calculation:
Calculates the SGPA for a specific semester. It is calualted by by summing the grade points of all the courses in that specific semester you have taken and dividing that total by the number of courses in the "courses".

Show Details:
Displays all the course details saved in "courses". This includes information such as course names, grades, and credits for each semester you have entered, giving you a complete overview of your academic record.

Add Course Detail:
Allows you to add new course details to the "courses" file. This includes entering course names, grades, and credits, which are then used to calculate the SGPA for that semester and the CGPA for your overall performance.

Exit:
Exits the program.
