This program solves a Sudoku puzzle using the Backtracking algorithm. 
The user is required to manually input the Sudoku puzzle in a 2D array format within the program. The algorithm will then attempt to solve the puzzle. If the puzzle is solvable, the program will output the solved Sudoku grid; if not, it will display the message "The provided puzzle is unsolvable".

Learning outcome:
  Gained experience in implementing backtracking algorithms to solve puzzles.
